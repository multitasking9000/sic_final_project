# Cat vs Dog Image Classification

An AI capstone project developed as part of the Samsung Innovation Campus (SIC) AI program.

The project explores image classification using traditional machine learning, custom Convolutional Neural Networks (CNNs), and transfer learning.

## Project Objectives

- Explore and understand the Cat vs Dog image dataset.
- Perform exploratory data analysis (EDA).
- Clean and preprocess image data.
- Build traditional machine learning baselines.
- Extract image features using HOG and PCA.
- Develop and train a custom CNN.
- Apply data augmentation and transfer learning.
- Evaluate and compare model performance.
- Deploy the best-performing model using Streamlit.

## Technologies

- Python
- PyTorch
- Scikit-learn
- NumPy and Pandas
- Matplotlib
- Jupyter Notebook
- Streamlit
